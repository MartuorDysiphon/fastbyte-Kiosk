# 🍔 Fast Food Kiosk System

A modern, fully functional self-service kiosk system for fast food restaurants built with React.

## ✨ Features

- 🔐 **Authentication** - Clerk-powered user authentication
- 📱 **Responsive Design** - Optimized for touchscreen kiosks and tablets
- 🛒 **Cart Management** - Add, update, and remove items from order
- 🔍 **Search Functionality** - Search menu items by name or description
- 📧 **Order Submission** - Formspree integration for order notifications
- 🧾 **Digital Receipt** - Downloadable .txt receipt with order details
- 💾 **Persistent Cart** - Saves cart to localStorage
- 🎨 **Modern UI** - Beautiful gradient designs and smooth animations

## 🚀 Quick Start

### Prerequisites
- Node.js 16+ and npm
- Clerk account (for authentication)
- Formspree account (for order submissions)
